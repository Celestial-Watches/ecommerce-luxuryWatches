Admin Panel go through:

### 1. Dashboard

No specific table is needed here because the dashboard typically aggregates data from other tables (like orders, products, and customers) for display.

### 2. Order Management

- order_id: Unique identifier for each order, `AUTO_INCREMENT` means the database automatically generates a new unique value for each row.
- customer_id: Links the order to a customer in the `customers` table. This is necessary to know who placed the order.
- order_date: The date and time when the order was placed. This is important for tracking and analytics.
- order_status: Tracks the current state of the order. Using `ENUM` restricts the values to predefined states, ensuring data consistency.
- total_amount: The total cost of the order. `DECIMAL(10, 2)` allows precise representation of money.
- shipping_address and billing_address: Store the customer's shipping and billing addresses, which are necessary for fulfilling the order.
- payment_status: Indicates whether the order has been paid for.
- payment_method: Describes how the payment was made (e.g., Credit Card, PayPal).
- tracking_number: Stores the shipping tracking number for the order, allowing customers to track their shipment.
- created_at: Automatically stores the timestamp when the record is created.
- updated_at: Updates the timestamp whenever the record is modified.
- FOREIGN KEY: Ensures that `customer_id` exists in the `customers` table, maintaining referential integrity.

#### order_items

- order_item_id: Unique identifier for each item in an order.
- order_id: Links the item to a specific order.
- product_id: Identifies which product was ordered.
- quantity: The number of units ordered.
- price: The price per unit of the product.
- discount: Any discount applied to the product.
- total: The total price for this line item (considering quantity and discount).
- FOREIGN KEY: Links `order_id` to the `orders` table and `product_id` to the `products` table, ensuring valid references.

### 3. Product Management

- product_id: Unique identifier for each product.
- product_name: The name of the product.
- description: A detailed description of the product.
- brand: The brand of the product.
- model: The model of the product.
- price: The original price of the product.
- discount_price: The price after any discount is applied.
- stock_quantity: The number of units available in stock.
- sku: The unique Stock Keeping Unit identifier.
- category_id: Links the product to a category in the `product_categories` table.
- status: Indicates whether the product is currently available for purchase.
- created_at and updated_at: Automatically track when the product was created and last updated.

#### product_categories

- category_id: Unique identifier for each product category.
- category_name: The name of the category.
- description: A description of the category.

### 4. Inventory Management

- inventory_id: Unique identifier for each inventory record.
- product_id: Links the inventory record to a product.
- stock_quantity: The number of units currently in stock.
- reorder_level: The stock level at which new inventory should be ordered.
- warehouse_location: The location of the product in the warehouse.
- last_updated: Automatically updates when the inventory record is modified.
- FOREIGN KEY: Links `product_id` to the `products` table, ensuring inventory records are associated with valid products.

### 5. Customer Management

- registration_date: The date the customer registered.
- membership_status: The customer's membership level, which may affect pricing, access to features, etc.
- created_at and updated_at: Automatically track when the customer record was created and last updated.

### 6. Sales and Analytics Management

- metric_name: Name of the metric being tracked (e.g., Total Sales).
- metric_value: The value of the metric.
- date_range: The date range over which the metric was calculated.

### 7. Promotion and Discount Management

- promotion_name: Name of the promotion.
- discount_percentage: The discount percentage offered.
- start_date and end_date: The period during which the promotion is active.
- promotion_code: A code customers can use to redeem the promotion.
- status: Whether the promotion is currently active.

### 8. Content Management

- page_id: Unique identifier for each page.
- title: Title of the page.
- slug: URL-friendly version of the title.
- content: The main content of the page.
- meta_description and meta_keywords: Used for SEO purposes.
- created_at and updated_at: Track when the page was created and last updated.

### 9. User Management

- user_id: Unique identifier for each user.
- username: The user's username.
